# Security policy

Cloud Agent can read and, with approval, change cloud infrastructure, so security reports are taken seriously.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository (Security → Report a vulnerability). Do not open a public issue for security problems. Include affected version, impact and reproduction steps, and avoid including real credentials or customer data.

You can expect an acknowledgement within a few days. This is a volunteer-maintained project without a formal SLA.

## Scope

In scope: scope/authorization bypass, approval or policy bypass, secret leakage, prompt-injection paths that lead to tool misuse, path traversal in repository access, audit-log tampering. Out of scope: findings that require already-compromised credentials or local machine access.

## Supported versions

Only the latest 0.x release receives fixes.
