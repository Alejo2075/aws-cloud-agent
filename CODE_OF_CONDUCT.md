# Code of Conduct

We want a respectful, harassment-free community. In this project and its spaces:

- Be considerate and assume good faith; critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or publishing others' private information.
- Accept feedback gracefully and give it constructively.

Maintainers may remove comments, issues or contributions that violate these principles and may restrict participation. Report concerns privately to the repository owner through GitHub. This statement follows the spirit of the Contributor Covenant.
